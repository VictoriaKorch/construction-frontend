# Лабораторная работа: Разработка SPA на React

## Описание страниц и компонентов

### 1. Навигационная панель (TabBar)
Расположена в нижней части экрана и обеспечивает маршрутизацию. Содержит 4 пункта:
* **Лента** (`/construction/feed`) — просмотр карточек строительных проектов в полноэкранном режиме.
* **Добавить** (`/construction/add`) — страница публикации нового проекта. Кнопка доступна (кликабельна) только для авторизованных пользователей.
* **Плитка** (`/construction`) — главная страница со списком объектов строительства.
* **Вход / Выход** (`/users/login`) — переход на страницу авторизации (для гостей) или кнопка выхода из системы (для авторизованных застройщиков).

### 2. Страница плитки (Каталог)
Главная страница приложения для обзора всех доступных строительных проектов и показателей стоимости.
* **Поля и элементы:**
  * Фильтр-слайдер: Два сопряженных ползунка для выбора минимальной и максимальной цены (руб/м²).
  * Текстовый вывод диапазона: Отображает текущие выбранные значения («От» и «До»).
  * Кнопка «Найти»: Кнопка отправки формы, по нажатию которой выполняется загрузка отфильтрованного списка карточек с бэкенда.
* **Карточка строительного объекта:**
  * Содержит изображение (фото объекта либо заглушку `default.jpg`), название проекта, стоимость (руб/м²) и количество лайков.
  * Для авторизованного создателя карточки отображается кнопка «Удалить».
  * Клик по карточке открывает её детальный просмотр в Ленте.

### 3. Страница ленты
Полноэкранный просмотр строительных объектов в стиле вертикальной ленты (по ID карточки).
* **Поля и элементы:**
  * Медиаплеер: Фоновое видео (`.mp4`) или статичное изображение (фото проекта либо `default.jpg`), в зависимости от данных карточки.
  * Заголовок и детали: Название строительного объекта, стоимость (руб/м²) и площадь (м²).
  * Интерактивные элементы: Кнопка лайка (доступна для нажатия авторизованным пользователям, меняет цвет при активации) и кнопка «Далее» (↓) для перехода к следующему проекту.
  * Блок описания: Текст с описанием проекта с выравниванием по левому краю и кнопкой раскрытия «Ещё» / «Скрыть».

### 4. Страница добавления проекта
Форма для создания и публикации новых строительных услуг. Процесс разделен на работу с черновиком и финальную публикацию.
* **Поля и элементы:**
  * Загрузка медиа: Поля для выбора файла изображения (`.jpg`, `.png`) и видеофайла (`.mp4`) с функцией автоматического предварительного просмотра (превью).
  * Текстовые поля: «Название проекта» и «Описание».
  * Числовые поля: «Цена (руб/м²)» и «Площадь (м²)».
  * Кнопки действий: «Далее» (создание черновика) и «Опубликовать» (финальное размещение карточки в каталоге).
  * Валидация: Обязательные поля подсвечиваются красным цветом при попытке отправить пустую форму.

### 5. Страница авторизации
Экран для входа застройщиков в систему для получения прав на публикацию, удаление и лайки.
* **Поля и элементы:**
  * Текстовое поле: «Имя пользователя».
  * Поле пароля: «Пароль».
  * Кнопка «Войти»: Отправляет данные через POST-запрос на сервер для проверки и создания сессии.
  * Блок ошибок: При вводе неверных данных выводится уведомление «Ошибка авторизации. Проверьте логин и пароль.»
