# Лабораторная работа № 5: Разработка базового SPA на React

## Описание страниц и компонентов

### 1. Навигационная панель (TabBar)

Расположена в нижней части экрана и содержит 4 пункта:

* **Лента** (`/construction/feed`) — просмотр карточек строительных проектов в полноэкранном режиме.
* **Добавление** (заглушка) — в данной лабораторной работе страница не открывается, подготовлена для будущих релизов.
* **Плитка** (`/construction/catalog`) — главная страница со списком объектов строительства.
* **Вход** (заглушка) — страница авторизации, зарезервирована для следующих лабораторных работ.

### 2. Страница плитки

Главная страница приложения для обзора всех доступных строительных проектов и показателей стоимости.

* **Поля и элементы:**
  * Фильтр-слайдер: Два сопряженных ползунка для выбора минимальной и максимальной цены (0–100000 руб/м²).
  * Текстовый вывод диапазона: Отображает текущие выбранные значения («От» и «До»).
  * Кнопка «Найти»: Кнопка отправки формы, по нажатию которой выполняется фильтрация списка карточек.
* **Карточка строительного объекта:**
  * Содержит изображение (уникальное фото объекта, например, `house2.jpg`, либо заглушку `default.jpg` при отсутствии медиа), название проекта, стоимость (руб/м²), количество лайков и условную кнопку «Удалить» для созданных пользователем карточек.
  * Клик по карточке открывает её в Ленте.

### 3. Страница ленты

Полноэкранный просмотр строительных объектов в стиле вертикальной ленты.

* **Поля и элементы:**
  * Медиаплеер: Фоновое видео (например, `house1.mp4`) или статичное изображение (фото проекта либо `default.jpg`), в зависимости от данных конкретной карточки.
  * Заголовок и лайки: Название строительного объекта и счетчик лайков.
  * Кнопка «Далее» (↓): Переключает на следующий строительный объект в списке (с циклическим возвратом).
  * Блок описания: Текст с описанием проекта с выравниванием по левому краю и кнопкой раскрытия «Ещё» / «Скрыть».
  * Параметры: Стоимость (руб/м²) и площадь (м²).
